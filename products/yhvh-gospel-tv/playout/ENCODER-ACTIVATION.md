# Encoder activation checklist

1. Mount `YHVH_CONTENT_VAULT` with approved media.
2. Populate `playout/broadcast-inputs.json` only with content that has `status: READY`, `rightsStatus: CLEAR`, `qcStatus: PASS`, a valid territory, and an existing media file.
3. Configure `YHVH_CONTROL_TOKEN` with a strong secret.
4. Configure `YHVH_RTMP_URL` only when an authorized RTMP destination and credential are available.
5. Start the service and inspect `/health` and `/api/broadcast`.
6. Use the owner-authenticated broadcast console at `/broadcast` to start the encoder.
7. Verify HLS playback at `/hls/playlist.m3u8`.

The system intentionally refuses to start when the rights/QC/territory gate has no valid inputs. No stream key, credential, licence or broadcast clearance is generated by the software.
