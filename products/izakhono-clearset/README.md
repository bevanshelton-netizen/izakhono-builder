# IZAKHONO CLEARSET™

**Collect → Classify → Reconcile → Reserve → Settle → Release**

CLEARSET is the obligation and available-cash layer.

It separates:
- third-party/merchant money;
- VAT provision where applicable;
- estimated income-tax/provisional-tax reserve;
- provider costs;
- refunds/chargebacks;
- disputed funds;
- other contractual/statutory obligations;
- truly available operating cash.

It is an accounting/reserve engine, not a tax-evasion mechanism and not a substitute for a registered tax practitioner. Complex/cross-border cases escalate instead of guessing.

No amount is labelled **AVAILABLE** until beneficial ownership, ledger posting, obligation classification and reserve funding are confirmed.
