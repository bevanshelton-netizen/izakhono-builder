# Ready Criteria

The Media Core foundation is merge-ready when repository CI passes. Production is ready only after the owned node passes:

1. control-plane health;
2. MediaMTX health;
3. authenticated RTMP/SRT ingest;
4. HLS playback;
5. WebRTC playback;
6. schedule/EPG validation;
7. recording and storage checks;
8. TLS and secret checks;
9. backup/restore check;
10. end-to-end paid-channel provisioning test.
