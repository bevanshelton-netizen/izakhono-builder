# IZAKHONO OS — Global Product Strategy

## Mission

Build a desktop operating system people around the world can understand in minutes, trust with their data, and move to without fear.

The product does not win by copying Windows or macOS. It wins by being simpler, more transparent, more respectful of privacy, and easier to recover when something goes wrong.

## Why people should want to move

### 1. Simplicity first

The main desktop experience revolves around six clear tasks:

- Internet
- My Files
- Apps
- Settings
- Updates
- Help Me

A first-time user should not need to understand operating-system terminology.

### 2. Privacy as a product feature

IZAKHONO OS itself does not track the user.

No advertising ID. No behavioural telemetry. No hidden analytics. No forced cloud account.

Privacy must be visible in the interface and auditable in the source and release process.

### 3. Familiar migration

The migration experience must guide users through:

- importing Documents, Pictures, Music and Videos
- importing browser bookmarks where technically possible
- importing Wi-Fi configuration where safe and permitted
- identifying installed Windows applications
- suggesting native or web alternatives
- identifying applications that may work through compatibility layers
- keeping a copy of the original data until the user chooses otherwise

No migration tool may delete the original user's files automatically.

### 4. Worldwide usability

The long-term product must support:

- major world languages
- right-to-left languages
- African languages
- Asian scripts
- Latin, Cyrillic, Arabic and Indic scripts
- full Unicode fonts
- local date/time formats
- local keyboard layouts
- accessibility-first navigation

The first release may ship with a smaller language set, but the architecture must not assume English.

### 5. Works on ordinary hardware

The system should run well on mainstream consumer PCs and extend the useful life of older hardware where technically reasonable.

Product targets:
- fast boot
- low idle resource usage
- responsive file browsing
- no unnecessary background services
- graceful operation on modest RAM and storage

### 6. Safe updates and recovery

Updates must explain:
- what is changing
- why it matters
- whether a restart is needed

Future stable releases should provide:
- restore points
- rollback after failed updates
- recovery mode
- encrypted backup options
- user-visible health status

### 7. Applications without confusion

Apps should be discoverable from one place.

The application strategy should combine:
- native Linux packages
- Flatpak applications
- web applications
- selected compatibility layers for Windows software where lawful and technically appropriate

The user should see one catalogue rather than needing to understand packaging technologies.

### 8. Global commercial model

The consumer operating system should remain free to download and use.

Revenue should come from optional services rather than tracking:
- enterprise support
- OEM certification
- device-management services
- business backup
- professional support
- training
- enterprise deployment
- commercial application distribution services

No revenue model may depend on selling behavioural data.

## Switching promise

A person trying IZAKHONO OS should be able to answer these questions positively:

- Can I understand this?
- Can I find my files?
- Can I browse the web?
- Can I install apps?
- Can I connect Wi-Fi and a printer?
- Can I recover if something goes wrong?
- Can I use it without being tracked?
- Can I return to my old system if I am not ready?

If the answer to any of these is no, the product is not ready for broad migration.

## Global launch gates

Before a public migration campaign, IZAKHONO OS must pass:

1. Boot and install tests on representative hardware.
2. Privacy release gate.
3. Update and rollback tests.
4. Wi-Fi, Bluetooth, audio and printer tests.
5. File migration tests.
6. Accessibility review.
7. Language/localisation review.
8. Browser and office-workflow tests.
9. Security review.
10. Clear licensing and trademark review.
11. Public support and recovery documentation.
12. Verified ISO hashes and signed release metadata.

## Positioning

The headline product promise:

> **Your computer. Made simple. No tracking.**

Supporting promise:

> **Familiar enough to start today. Powerful enough to grow with you.**
