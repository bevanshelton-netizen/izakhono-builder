# IZAKHONO OS Adoption Principles

1. **Never trap the user.** Dual-boot, live trial and reversible migration should be supported where technically safe.
2. **Never hide complexity by removing control.** Easy mode sits on top of a complete operating system.
3. **Never monetize the user through tracking.**
4. **Never claim compatibility that has not been tested.**
5. **Never delete source files during migration automatically.**
6. **Never require a cloud account for basic use.**
7. **Never make recovery harder than installation.**
8. **Never make accessibility an add-on.**
9. **Never assume one country, language, currency or keyboard layout.**
10. **Never call a release global-ready until hardware, privacy, recovery and localisation gates have passed.**
