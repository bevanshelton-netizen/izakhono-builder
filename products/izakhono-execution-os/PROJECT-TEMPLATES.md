# IZAKHONO EXECUTION OS — PROJECT TEMPLATES

## 1. Digital Product Sale

**Objective:** make a digital product commercially available.

Stages:
- confirm product asset
- confirm offer and price
- build/verify sales page
- verify checkout
- verify delivery path
- create organic campaign pack
- publish approved campaign
- capture leads
- reconcile confirmed sales
- report conversion and revenue

## 2. Service Launch

**Objective:** turn a service into a lead-to-customer workflow.

Stages:
- define service
- define ideal customer
- package offer
- create landing page
- create enquiry/booking form
- connect CRM
- create follow-up sequence
- launch organic campaign
- measure enquiries
- convert and report

## 3. Website / Project Completion

**Objective:** finish an existing project rather than repeatedly redesigning it.

Stages:
- inspect current state
- list acceptance criteria
- identify blockers
- complete missing functionality
- test critical flows
- deploy
- smoke-test public URL
- owner handover
- mark completed only with evidence

## 4. Lead Generation Campaign

**Objective:** create qualified demand without paid spend by default.

Stages:
- offer
- audience
- campaign creative
- landing page
- lead capture
- automated follow-up
- organic distribution
- conversion tracking
- optimisation

## 5. Internal Automation

**Objective:** remove a repetitive manual workflow.

Stages:
- document current workflow
- identify decision points
- define safe automation boundary
- implement
- test failure paths
- add human approval where required
- measure time/error reduction
- release

## Common output
Every template produces:

- project ID
- objective
- acceptance criteria
- current state
- next action
- blockers
- evidence
- marketing assets, when applicable
- metrics
- completion status
