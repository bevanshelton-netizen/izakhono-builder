# Third-party reference

## Microsoft Call Center AI

IZAKHONO VOICE™ was informed by the public architecture of Microsoft's `call-center-ai` repository:

https://github.com/microsoft/call-center-ai

The referenced project is licensed under the Apache License, Version 2.0. Its license permits use, reproduction and derivative works subject to the license conditions, including preservation of applicable notices and marking modified files when redistributing modified files.

This IZAKHONO VOICE foundation is a new provider-neutral implementation. It does not copy Microsoft source files. The Microsoft project is treated as an architectural/reference component for capabilities such as real-time call handling, structured case data, RAG, reminders, human transfer and post-call synthesis.

Microsoft/Azure services remain optional adapters. IZAKHONO's source-of-truth, orchestration, customer state, security controls and infrastructure strategy remain owned-first.
