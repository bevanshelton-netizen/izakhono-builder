# Storefront Prototype

This directory contains a static, brand-neutral concept homepage for the $7 Topic PDF Publishing Programme.

## Purpose
- Demonstrate the proposed international customer-facing presentation.
- Explore the homepage hierarchy, category navigation, featured guide treatment, reader journey and trust messaging.
- Provide a concrete review artefact before implementation of a production storefront.

## Safety and status
- This is a non-production HTML/CSS prototype with no JavaScript, analytics, forms, checkout, payment integration, external assets or customer-data collection.
- “TOPIC GUIDES” is a working label, not an approved final brand name or trademark.
- The sample household-budget guide is an editorial draft and is explicitly marked not for sale.
- No testimonial, review, customer count, endorsement or sales claim is fabricated.
- The prototype does not authorise public deployment, domain registration, paid hosting or any expenditure.

## Preview locally
Open `index.html` in a modern browser. No build step or external dependency is required.
