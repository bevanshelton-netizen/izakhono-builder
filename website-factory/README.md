# IZAKHONO Website Factory v1

A standalone Website Factory surface for the IZAKHONO portfolio.

## Production contract
- One customer order becomes one structured website job.
- The build engine is independent of any single execution node.
- NODE01 is a worker/execution node, not the product.
- Required gates: HTTPS, privacy, accessibility, performance, mobile QA and deployment proof.
- External hosting remains a reversible fallback.

## Current v1
This release establishes the operator-facing factory surface and job intake contract. Backend orchestration, payment activation, domain provisioning, email provisioning and node scheduling are subsequent engine adapters.
