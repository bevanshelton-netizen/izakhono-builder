# IZAKHONO R10M — OPERATIONAL READINESS GATE

Status: Operational control specification v1

## Purpose
Turn the R10m funding programme from a document set into a controlled execution system.

## Operating rule
No application is considered READY merely because the narrative is complete. READY requires evidence, eligibility, budget reconciliation, ownership confirmation, submission authority, and a documented next action.

## Gate 1 — Corporate
- CIPC company documents
- Tax compliance evidence
- CSD evidence where applicable
- B-BBEE/ownership evidence
- Banking confirmation
- Directors/beneficial ownership records
- Company profile

Status: AMBER until current documentary evidence is loaded into the data room.

## Gate 2 — IP and technology
- IP ownership chain
- Source-control history
- Architecture documents
- Technical specifications
- Test/QC evidence
- TRL baseline per project
- Third-party dependency register
- Security architecture

Status: AMBER until each item is independently evidenced and indexed.

## Gate 3 — Funding eligibility
### TIA
Project A is the primary Technology Development Fund candidate. TIA describes TDF as supporting prototype development through operating-environment demonstration at TRL 4–7. Confirm final TRL, eligible costs, co-funding and current portal requirements before submission.

### SPII
Select exactly one defined development project if pursuing SPII. Confirm significant technological advance, South African development/production, South African IP ownership, qualifying costs, contribution requirement and non-overlap with other government funding.

Status: AMBER pending formal eligibility confirmation against current documents.

## Gate 4 — Financial control
Every budget line must have:
1. Amount
2. Project
3. Funding route
4. Qualifying/non-qualifying classification
5. Evidence required
6. Evidence owner
7. Payment/source record
8. No-overlap flag

Any unresolved line remains RED for submission purposes.

## Gate 5 — Commercial evidence
- Customer discovery
- Pilot design
- LOIs/contracts when actually obtained
- Pricing model
- Licensing model
- Strategic partner targets
- Revenue evidence where applicable

No pipeline prospect is represented as a customer.

## Gate 6 — Application readiness
A package becomes SUBMISSION-READY only when:
- Corporate gate = GREEN
- IP/technology gate = GREEN
- Funding eligibility gate = GREEN
- Financial control = GREEN
- Required declarations/forms complete
- Final narrative reconciles to budget
- All claims trace to evidence
- Internal approval recorded

## Gate 7 — Submission and monitoring
For each submitted application record:
- Funder
- Instrument
- Project
- Submission date
- Application/reference number
- Requested amount
- Applicant contribution
- Key milestones
- Funder contact/channel
- Follow-up date
- Questions received
- Responses submitted
- Decision/status

TIA states a desired investment-decision turnaround of 15 weeks for applications above R1m and below R15m, measured from receipt of a full application; this is a desired turnaround, not a funding guarantee.

## Capital-stack rule
Do not count a funding source toward the R10m achieved total until the relevant capital is contractually awarded/committed and available under its terms.

Pipeline target != secured capital.

## R10m dashboard states
- RED — blocked / missing evidence / eligibility unresolved
- AMBER — work in progress / evidence incomplete
- GREEN — submission-ready
- SUBMITTED — application formally lodged
- DILIGENCE — funder reviewing
- APPROVED — written approval received
- CONTRACTED — agreement executed
- FUNDED — funds received/available
- COMMERCIAL — customer revenue/licence proceeds received

## Immediate execution queue
1. Load corporate evidence.
2. Build IP register and chain-of-title file.
3. Establish TRL evidence per Project A/B/C.
4. Reconcile all budgets against eligible/non-eligible categories.
5. Prepare TIA Project A application pack.
6. Select and freeze the SPII project before any SPII submission.
7. Prepare strategic investor data room.
8. Start documented enterprise pilot outreach.

## Hard controls
- No fabricated evidence.
- No duplicate government-funded costs.
- No unsupported regulatory claims.
- No unsupported customer or investor claims.
- No submission before the readiness gate passes.
- Preserve IZAKHONO IP ownership wherever commercially and legally appropriate.
