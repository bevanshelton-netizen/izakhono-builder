# IZAKHONO Website Factory

The portfolio does not build websites one at a time anymore.

## Operating model
1. Define the product in a small JSON manifest.
2. Generate the responsive premium shell, brand tokens and QA record automatically.
3. Existing applications keep their own engines and receive the shared experience layer through adapters.
4. Human work is reserved for real brand/product differences, not repetitive layout work.
5. Production stays blocked until browser QA and HTTPS verification pass.

## Generated baseline
- international responsive layout
- product name and value proposition above the fold
- primary CTA
- trust/proof blocks
- mobile navigation behavior
- visible keyboard focus
- reduced-motion support
- no behavioural tracking
- no advertising IDs
- no UTM/referral attribution
- no remote-font dependency

## Rule
Do not hand-build a new IZAKHONO brochure, landing or campaign site when the factory can generate the foundation.
