# I-CONNECT Staging Track

This branch is reserved for the I-CONNECT staging integration track.

## Release boundary

I-CONNECT is an African-owned connectivity product under IZAKHONO. The staging track must remain isolated from unrelated applications in `main`.

## Current status

- Product architecture: complete
- Core MVP package: prepared separately for integration
- Customer portal MVP: prepared separately for integration
- Operations console MVP: prepared separately for integration
- Payment/provisioning contracts: defined
- Carrier/MVNO integration: pending host-network commercial and technical onboarding
- RICA/compliance production integration: pending regulatory and partner requirements
- Production deployment: pending approved infrastructure release

## Safety rule

Do not represent this branch or the shared builder application as a live telecom service. Production activation requires verified carrier connectivity, compliant RICA, payment credentials, operational controls, and release verification.
