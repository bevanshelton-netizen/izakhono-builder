# IZAKHONO BUILD ANYTHING v1

Release intent: owner-controlled one-sentence creation for apps, websites, games and software.

## Build chain

1. Owner enters one brief.
2. IZAKHONO SUPER AI enriches the build intent when the protected workflow route is available.
3. A deterministic local planner remains the safe fallback.
4. Builder creates the project and applies the portfolio baseline modules.
5. Builder generates a repository-ready source bundle.
6. Deterministic validation must pass.
7. Validated source is committed into the private IZAKHONO internal repository.
8. External mirrors and public deployment remain separate evidence-gated actions.

## Safety / ownership rules

- IZAKHONO source is the source of truth.
- External AI and hosting providers are replaceable adapters.
- No browser-side model or deployment secrets.
- No automatic paid-media spend.
- No automatic third-party legal-term acceptance.
- No automatic external source publication.
- Public-live status requires HTTPS and end-to-end acceptance evidence.
- No behavioural tracking or advertising identifiers are introduced by this feature.

## v1 scope

The first release supports the product types `app`, `website`, `game` and `software`, with reusable modules for identity, payments, CRM/leads, media, learning, marketplace, AI, notifications/chat, workflow automation, publishing, growth, affiliate operations, document flow, game scaffolding, and SEO/discovery.


## Product-factory benchmark UX

The Owner Builder now presents quick-start product briefs for common build classes (AI content platform, SaaS landing page, task management, client dashboard and e-commerce) while keeping the one-sentence prompt as the primary interface.

The generated release candidate is one project with an installable Web/PWA baseline and explicit Android/iOS/desktop release manifests. Mobile manifests are preparation records only: signing and store-submission evidence remain hard release gates.

This benchmark work does not introduce a dependency on any competing app-builder provider. IZAKHONO source, SUPER AI, internal repositories and owned-first deployment remain authoritative.
