# IZAKHONO SHARING & ADVERTISING LINK RULES v1

## Non-negotiable commercial rule
Every IZAKHONO website and every IZAKHONO advertisement must provide a direct path from attention to action.

## Website sharing standard
Every public-facing IZAKHONO site must include visible, functional share controls appropriate to the content and platform. Share controls should support native/browser sharing where available and direct sharing links where supported.

Minimum expectations:
- Share the current page or relevant product/content page.
- WhatsApp sharing where appropriate for the market.
- Facebook sharing where supported.
- X sharing where supported.
- LinkedIn sharing where appropriate for professional/business content.
- Native Web Share API on supported mobile browsers, with graceful fallback.
- Copy-link action as a universal fallback.
- Share controls must work on mobile and desktop.
- Share URLs must resolve to the exact page being promoted, not merely the homepage.
- Open Graph/social metadata and share imagery must be maintained so shared links render professionally.

## Advertising click-through standard
Every IZAKHONO advert must contain a functional clickable destination. No advert is considered complete if it only displays a phone number, URL as text, QR code, or visual CTA without a verified click path when the publishing medium supports clickable links.

The destination must be the most relevant conversion page:
- Buy Now → verified checkout/product page.
- Apply Now → application/enrolment page.
- Register → registration page.
- Book Now → booking flow.
- Get a Quote → quote/order page.
- Visit Site → exact campaign landing page.
- Listen/Watch → exact media destination.
- Contact/WhatsApp → verified contact channel.

## Link integrity
Before an advert is published:
1. Verify the destination responds successfully.
2. Verify the CTA lands on the intended page.
3. Verify mobile and desktop behavior where applicable.
4. Verify payment/checkout links when the advert promises purchase.
5. Verify that tracking parameters do not break the destination.
6. Verify there are no placeholder, dead, redirected-to-nowhere, or misleading links.

## CTA rule
Use clear action language such as Buy Now, Get Started, Apply Now, Book Now, Enrol Now, Listen Now, Watch Now, Get a Quote, or Explore the Offer. Avoid vague Click Here labels. Navigation links should use anchors and action controls should use buttons where semantically appropriate.

## Revenue rule
If a verified checkout exists, the advert should lead directly to that checkout rather than forcing the customer through unnecessary intermediate pages.

If checkout is not yet connected, the advert must use a truthful order/enquiry destination and must not imply that instant payment is available.

## Graphics-worker requirement
Graphics workers must receive the destination URL/CTA as part of the creative brief. The final creative must reserve a clear, visually prominent clickable CTA area for digital placements and must produce platform-appropriate variants when the publishing channel requires different link treatments.

## QA gate
A website/ad campaign is not commercially complete until:
- share controls are functional where applicable;
- every digital advert has a verified clickable destination;
- Buy Now creatives lead directly to verified checkout where available;
- destination pages match the promise of the advert;
- mobile interaction is tested;
- no broken CTA/share links remain;
- the final destination and commercial status are truthful.

This rule is part of the IZAKHONO world-class design and revenue system and applies by default to new builds, rebuilds, landing pages, campaign pages, social creatives, digital catalogues, and promotional assets.
